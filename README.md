# StudyMate AI

AI-powered study and productivity assistant for college students.

## Features
- AI Study Planner (demo)
- Smart Task Manager
- Personalized AI recommendations
- Pomodoro Focus Timer
- Mood & Stress Check-in
- AI Study Chatbot (demo)
- Progress Dashboard
- Exams & Deadlines
- Responsive mobile/web interface
- LocalStorage demo data

## Design Thinking
**Empathize → Define → Ideate with AI → Prototype → Validate**

## Run locally
Open `index.html` in a browser.

For GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save and open the generated Pages URL.

> This is a college-project prototype. AI responses are demo/local logic and the mood feature is not a medical diagnosis system.
